# Creature Trails — Wildwood Edition
A playable 3D creature-adventure vertical slice using Three.js + Vite.
Features: third-person exploration, procedural village, enterable house interior, companion creature, tall-grass encounters, turn-based battles, emulator-style touch controls, keyboard controls.

Run: `npm install` then `npm run dev`
Build: `npm run build`
Vercel: Import repository, Framework Vite, Build `npm run build`, Output `dist`.

This is an original prototype, not a Pokémon game or Nintendo asset reproduction. Online multiplayer, full campaign, and advanced character animation are not included in this build.
